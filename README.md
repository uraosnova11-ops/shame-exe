# Юрий CRM — состояние проекта

Это обновление существующего MVP. Исходники **не являются готовым Windows-приложением**: в доступной среде отсутствовали Telethon и PyInstaller, установка из PyPI была заблокирована сетью. `.exe` не собран, реальный вход и отправка через Telegram не проверены. Не включайте кампанию, пока не пройдены проверки на настоящем аккаунте и тестовом получателе.

## Изменения

- Вместо Bot API интегрирован пользовательский MTProto-клиент на Telethon. Вход: `api_id`, `api_hash`, телефон, код, пароль 2FA. Все значения вводятся только в интерфейсе приложения. Пользовательская сессия (`StringSession`) и ключи внешних сервисов запечатываются Windows DPAPI для текущей учётной записи и сохраняются в `%LOCALAPPDATA%\YuriCRM`.
- Старые числовые бот-чаты помечаются как устаревшие при миграции базы; отправка в них блокируется. Для нового обращения указываются подтверждённый деловой `@username` и источник его связи с компанией, отдельно фиксируется разрешение на предложение.
- Сообщение отправляется с личного аккаунта. Если нет публичного HTTPS-адреса для демо, прикладывается скриншот страницы. Исход попытки записывается до сетевого вызова как неопределённый, при неоднозначной ошибке автоматически не повторяется. При FloodWait и других ограничениях кампания останавливается. Отказ клиента блокирует следующие обращения.
- Мастер первого запуска последовательно показывает профиль, Telegram, сервисы поиска, кампанию, тестовую отправку и включение режима. Отображается подключённый аккаунт. Добавлена кнопка отключения сессии. `launcher.py` предназначен для оконного запуска будущей сборки.

## Что проверено

- `python -m unittest -v test_app.py`: импорт → анализ → демо → разрешённый контакт → вызов **подставного** транспорта → сохранение результата → блокировка повтора → отказ.
- `node --check` для скрипта интерфейса; HTTP-панель отвечает в локальном тестовом процессе.
- **Не проверены:** MTProto-авторизация, доставка реальному Telegram-получателю, DPAPI в обычной учётной записи Windows, сборка и запуск `.exe` без среды разработки. В ограниченной среде DPAPI не смог открыть хранилище профиля Windows, поэтому его реальную работу нужно проверить отдельно.

## Подключения для завершения

1. Telegram API ID и API hash: [my.telegram.org/apps](https://my.telegram.org/apps), бесплатно. Telegram может потребовать код в приложении, email или иной поддерживаемый способ и пароль 2FA.
2. 2ГИС Places API: [платформа 2ГИС](https://platform.2gis.ru/). Тариф и права на контакты/отзывы зависят от договора. Без ключа доступен ручной импорт.
3. Яндекс Organization Search: [условия](https://yandex.com/dev/commercial/doc/en/concepts/geosearch), коммерческое подключение; сохранение данных допустимо только при соответствующем разрешении.
4. Публичный HTTPS-хостинг демо **не обязателен**, если Windows-браузер создаёт скриншот. Для ссылки нужен отдельный статический хостинг только каталога демо, без доступа к панели и API.

## Техническая схема

`app.py` — локальный HTTP-сервер, SQLite, поиск, очередь и демо. `telegram_user.py` — одна пользовательская MTProto-сессия в отдельном asyncio-потоке, события входящих личных сообщений и DPAPI. `index.html` — русская панель и мастер. `launcher.py` — оконная оболочка. `build_windows.ps1` — сценарий сборки **для разработчика**, который здесь не запускался. База остаётся в `%LOCALAPPDATA%\YuriCRM` между запусками.

Telegram предупреждает о санкциях за нежелательные коммерческие сообщения: [правила](https://telegram.org/tos), [FAQ по спаму](https://telegram.org/faq_spam). Публичный контакт не означает согласия. Подключение личной учётной записи не отменяет ограничения приватности и частоты. Приложение не обходит ограничения и не ротирует аккаунты.
