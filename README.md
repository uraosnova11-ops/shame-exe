# YuriCRM — Windows

YuriCRM работает в собственном настольном окне Windows. Приложение ищет компании Ростова-на-Дону через подключённые 2ГИС и Яндекс, проверяет сайты, создаёт локальные демостраницы и ведёт историю обращений. Основной и единственный канал отправки — личный аккаунт Telegram через MTProto. Электронная почта не используется.

## Первый запуск

1. Запустите `YuriCRM.exe` двойным щелчком. База и настройки сохраняются в `%LOCALAPPDATA%\YuriCRM`.
2. Получите собственные API ID и API hash на [my.telegram.org/apps](https://my.telegram.org/apps), затем введите их, номер телефона, код входа и при необходимости пароль 2FA в мастере YuriCRM.
3. При необходимости введите ключ 2ГИС и ключ Яндекс Карт. Без ключей доступен ручной импорт компании.
4. Настройте ниши, районы, лимит и часы работы. Отправьте тест на заранее согласованный @username и только после проверки включите кампанию.

API hash и Telegram-сессия не входят в исходный код или сборку. Сессия хранится в зашифрованном Windows DPAPI-файле текущего пользователя. Кнопка отключения выполняет выход и удаляет сохранённую сессию.

## Ограничения

Telegram может запретить первое сообщение из-за приватности, антиспам-ограничений или FloodWait. При таком ответе кампания останавливается. Приложение не угадывает Telegram по номеру телефона или названию: принимается только опубликованный деловой @username, связь которого с компанией подтверждена ссылкой на официальный сайт или карточку.

Публичный @username сам по себе не считается согласием на рекламу. Отправка из очереди требует отдельно сохранённого основания разрешения, готового демо и включённой кампании. Одна компания получает не более одного исходящего предложения; после отказа дальнейшие сообщения блокируются. Ответы личного Telegram поступают в раздел переписки через активную MTProto-сессию.

Windows CI проверяет локальный сценарий, наличие Telethon внутри EXE, запуск собственного окна, основные экраны и сохранение настроек после перезапуска. Реальная авторизация и доставка проверяются отдельно после ввода данных пользователем на согласованном тестовом аккаунте.
