# Юрий CRM — Windows

Приложение ищет компании Ростова-на-Дону через подключённые 2ГИС и Яндекс, проверяет сайт, создаёт локальный пример страницы и ведёт очередь обращений. В этой версии основным каналом служат сообщения деловым сообществам VK с подключённого пользовательского аккаунта VK. Старый Telegram-канал отключён, сохранённая Telegram-сессия удаляется при первом запуске обновления. Электронная почта в отправке не используется.

## Первый запуск

1. Запустите `YuriCRM.exe` двойным щелчком на Windows 10/11 x64. Настройки и база сохраняются в `%LOCALAPPDATA%\YuriCRM`.
2. Введите имя и город. В разделе VK укажите пользовательский токен с разрешением `messages`, полученный для собственного приложения согласно [документации VK](https://dev.vk.com/). Токен вводится только в интерфейсе, не в исходниках или CI. Доступ к сообщениям зависит от прав, которые VK выдаст вашему приложению.
3. При необходимости введите ключ 2ГИС (может быть платным), ключ Яндекс Карт (коммерческий доступ и отдельно разрешённое хранение) и токен MAX-бота. Без ключа карт доступен ручной импорт. Укажите публичный HTTPS-адрес, который действительно размещает каталог `/demo/`, иначе VK-отправка заблокирована. Приложение само не публикует демо в интернет.
4. Установите ниши, районы, лимиты и часы работы; отправьте тест в собственное или согласованное сообщество VK. Подтвердите получение внутри VK. После этого включите кампанию.

## Ограничения

Автоматическая отправка в VK выполняется лишь для выбранного делового сообщества с подтверждённой связью с компанией, отдельно записанным основанием разрешения и реально доступным демо. Одна компания получает не более одного исходящего обращения. При отказе очередь останавливается для неё; при ограничении частоты VK останавливается вся кампания. Публичная ссылка на сообщество сама по себе не означает согласие на рекламу.

MAX-бот может писать в уже начатый получателем диалог; токен MAX и флаг кампании можно настроить через интерфейс. WhatsApp Business Platform требует отдельной бизнес-интеграции, согласия адресата и правил шаблонов; в этой поставке отправка WhatsApp не реализована. Реальная отправка VK проверяется только после подключения вашего аккаунта и тестового сообщества. CI отдельно проверяет локальную логику, запуск собранного Windows EXE, интерфейс и сохранение настроек после повторного запуска.
